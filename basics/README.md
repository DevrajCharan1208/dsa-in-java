# Basics

| No. | Idea / Problem | Filename | Description |

| 3 | **Decimal to Binary** | [`DecToBin.java`](DecToBin.java) | Converts a decimal number provided as input into its binary equivalent. |
| 4 | **Factorial** | [`Factorial.java`](Factorial.java) | Computes the factorial of a given number. |
| 5 | **Prime Number Check** | [`IsPrime.java`](IsPrime.java) | Determines whether a given number is a prime number or not. |
