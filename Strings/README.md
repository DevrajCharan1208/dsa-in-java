# Strings in Java

This directory contains implementations of String-based problems and algorithms in Java.

## 📝 Topics Covered

| No. | Problem | Description | Solution Link |
|---|---|---|---|
| 1 | **Shortest Path from Directions** | Given a direction string (N/S/E/W), calculate the straight-line shortest distance from the origin using the Pythagorean theorem — O(n). | [`St01ShortestPath.java`](St01ShortestPath.java) |
| 2 | **Custom Substring** | Manually extracting a substring from a given start index to an end index without using built-in methods — O(n). | [`St02Substring.java`](St02Substring.java) |
| 3 | **Letter to Uppercase** | Capitalises the first letter of every word in a sentence using `StringBuilder` and `Character.toUpperCase()` — O(n). | [`St03LetterToUpperCase.java`](St03LetterToUpperCase.java) |
| 4 | **String Compression** | Compresses consecutive repeated characters into character + count format (e.g. `aaabb` → `a3b2`). Two approaches: `StringBuilder`-based and string concatenation — O(n). | [`St04StringCompression.java`](St04StringCompression.java) |
