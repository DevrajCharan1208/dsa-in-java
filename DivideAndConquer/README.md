# Divide and Conquer

This directory contains algorithmic implementations using the Divide and Conquer strategy in Java.

## 📝 Topics Covered

| No. | Problem | Description | Solution Link |
|---|---|---|---|
| 1 | **Merge Sort** | A stable, comparison-based sorting algorithm that divides the array into halves, sorts them, and merges them back — O(n log n). | [`DC01MergeSort.java`](DC01MergeSort.java) |
| 2 | **Quick Sort** | An efficient, in-place sorting algorithm that uses a pivot element to partition the array — O(n log n) average case. | [`DC02QuickSort.java`](DC02QuickSort.java) |
| 3 | **Search in Sorted & Rotated Array** | Finding a target element in a sorted array that has been rotated at some pivot point — O(log n). | [`DC03SortedRotatedArraySearch.java`](DC03SortedRotatedArraySearch.java) |

---
*Divide the problem, conquer the sub-problems, and combine the results!* 🧩
