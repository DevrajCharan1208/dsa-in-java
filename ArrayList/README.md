# ArrayList in Java

This directory contains algorithmic implementations and problems solved using Java's `ArrayList` data structure, often leveraging the Two Pointer approach.

## 📝 Topics Covered

| No. | Problem | Description | Solution Link |
|---|---|---|---|
| 1 | **Container with Most Water (Brute Force)** | Finding the maximum water that can be stored between two lines by checking all pairs — O(n²). | [`AL01WaterContainerBruteForce.java`](AL01WaterContainerBruteForce.java) |
| 2 | **Container with Most Water (Two Pointer)** | Optimized approach using two pointers starting at ends and moving inward — O(n). | [`AL02WaterContainerTwoPointer.java`](AL02WaterContainerTwoPointer.java) |
| 3 | **Pair Sum 1 (Brute Force)** | Finding if a pair with a given sum exists in an array by checking all pairs — O(n²). | [`AL03PairSumBruteForce.java`](AL03PairSumBruteForce.java) |
| 4 | **Pair Sum 1 (Two Pointer)** | Optimized approach to find a pair sum in a sorted array using two pointers — O(n). | [`AL04PairSum1SortedOptimized.java`](AL04PairSum1SortedOptimized.java) |
| 5 | **Pair Sum 2 (Rotated & Sorted)** | Finding a pair sum in a rotated sorted array using modular arithmetic with two pointers — O(n). | [`AL05PairSum2Optimized.java`](AL05PairSum2Optimized.java) |
